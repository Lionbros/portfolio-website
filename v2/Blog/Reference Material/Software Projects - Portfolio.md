# Software Projects — Personal Experiments & Hobby Builds

Software projects unaffiliated with any client — hobby and experimental builds where I learn by doing.

## Hobby & Experimental Projects

### WhatsApp Clone for IMAP Emails
Built a WhatsApp-style interface as an imitation inbox, wired to a real IMAP server so incoming emails arrive as chat messages. A fun way to rethink how email could look.

**Languages & tools:** Python, IMAP, HTML/CSS/JavaScript

### STEM Generator for Traktor
A custom interface built around the stemgen library, used to separate the different parts of a track. Built for DJ'ing, letting me isolate vocals, drums and instruments cleanly.

**Languages & tools:** stemgen library, custom UI, HTML/CSS/JavaScript

### Local Minecraft Server
A Minecraft server hosted from my local PC to play with friends.

**Tools:** Java, local networking setup

### Voice Cloning Experiments
Experiments with Omnivoice from Hugging Face to clone voices and explore audio AI.

**Languages & tools:** Python, Omnivoice, Hugging Face
