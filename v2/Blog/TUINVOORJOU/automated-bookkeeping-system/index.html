Automated Bookkeeping System

Category: Software & AutomationClient: TUINVOORJOU

The Problem

Running a garden design business means every order arrives as a WooCommerce e-mail. Copying each one into an Excel bookkeeping sheet by hand is slow, error-prone and eats hours every week.

What It Does

The system connects to the company mailbox over IMAP with TLS/SSL, watches for new WooCommerce order notification e-mails, and parses the full order into structured data: order number, date, customer name, e-mail, phone, billing and shipping addresses, line items, prices, VAT, shipping costs, payment method and order notes. It handles Dutch date formats and multi-part HTML e-mails automatically.

Workload Mapping

A built-in product catalogue maps every garden product (TUINSCHETS, TUINPLAN, BEPLANTINGSPLAN, 3D BEELDEN, DROOMTUINDEAL, and more) to an estimated workload in hours, scaled by garden surface area — from under 100 square metres up to more than 2500.

Into Excel

Each order is written into a macro-enabled Excel workbook with automatically generated headers, currency and hours formatting, colour-coded conditional formatting for project status, dropdown data-validation and live formulas for net margin and remaining hours.

Built to Be Safe

The script is duplication-safe, skipping order numbers it has already processed. It creates automatic backups before every write, retries when the file is locked, and safely closes and reopens Excel via process management. All configuration lives in an external JSON file.

Languages & Tools Python, Microsoft Excel VBA, IMAP, BeautifulSoup, openpyxl, psutil, JSON, Windows shell scripting
