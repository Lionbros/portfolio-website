Section 01

Software & Automation

Automated Bookkeeping System

An end-to-end order automation pipeline that eliminates manual bookkeeping entry — parsing WooCommerce orders into a structured Excel workbook.

Languages & tools: Python, Excel VBA, IMAP, BeautifulSoup, openpyxl

E-mail Attachment & Project Folder Automation

A desktop tool that reads incoming client e-mails and fully automates project intake — creating folders and downloading attachments by type.

Languages & tools: Python, tkinter, IMAP/SSL, Pillow, MIME parsing

Plattegrond Generator

A custom web tool that generates a correctly scaled blueprint of any Dutch or Belgian address in seconds, ready to print or share.

Languages & tools: JavaScript, PHP, OpenLayers, proj4js, BAG/GRB/CRAB, jsPDF

Tuincalculator

An interactive garden budget calculator that turns a visitor's wishes into a realistic cost estimate, with live charts and branded reporting.

Languages & tools: JavaScript, Tailwind CSS, Chart.js, PHP, WordPress REST API

Client Vragenlijst

A hardened custom intake form that gathers project wishes and file uploads, pushing everything into a folder-structured Google Drive workspace.

Languages & tools: JavaScript, PHP, Google Drive API (OAuth 2.0), TCPDF, CSRF & rate limiting
