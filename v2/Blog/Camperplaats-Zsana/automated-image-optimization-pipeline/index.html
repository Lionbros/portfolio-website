Automated Image Optimization Pipeline

Category: Software & AutomationClient: Camperplaats Zsana

The Problem

RAW and high-res photos from the photoshoot would have crushed the site's performance. Optimising dozens of images by hand is tedious and inconsistent.

The Pipeline

I built an automated pipeline that processes every image in a folder in one run: resizing to web-friendly dimensions, encoding to the modern WebP format, stripping unnecessary EXIF data, and sanitising filenames for clean URLs. The result is a fast site with sharp images and consistently smaller file sizes across the board.

Languages & Tools Python, Pillow/PIL, WebP encoding, EXIF metadata handling, batch resize & compression, filename sanitising
